# Remise à niveau JavaScript / TypeScript

Dépôt d'entraînement personnel : exercices pratiques et mini-projets pour consolider les fondamentaux de JavaScript moderne, TypeScript et React.

## Objectifs

- Maîtriser les fondamentaux de JavaScript moderne (ES2015+) : portée, closures, asynchrone, modules
- Pratiquer TypeScript : types, interfaces, génériques
- Construire de petites applications React et les publier

## Structure

```
remise-a-niveau/
├── semaine-1-javascript/
│   ├── 01-somme-pairs.js
│   ├── 02-group-by.js
│   └── ...
├── semaine-1-typescript/
└── semaine-2-react/
```

## Lancer un exercice

Prérequis : Node.js 18 ou plus récent.

```bash
node semaine-1-javascript/01-somme-pairs.js
```

## Progression

| Semaine | Thème | Statut |
|---|---|---|
| 1 | JavaScript moderne : tableaux, closures, asynchrone, modules | ✅ Terminé |
| 1 | TypeScript : types, interfaces, génériques | À venir |
| 2 | React : hooks, état, React Query, formulaires | À venir |

## Stack

JavaScript (ES2022), TypeScript, Node.js, React
